# Multi-Disease Prediction System

## Overview
The Multi-Disease Prediction System is a machine learning-based application designed to predict diseases using patient-provided medical data.

## Features
- Disease prediction using machine learning.
- User authentication.
- Prediction history management.
- AI-based health assistance.
- Hospital recommendations.
- Report generation.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- SQLite
- ReportLab

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/prashanth-a8074/Multi-Disease-Prediction-System.git
   ```

2. Open the project folder:
   ```bash
   cd Multi-Disease-Prediction-System
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Train the machine learning models:
   ```bash
   python train_models.py
   ```

5. Run the application:
   ```bash
   streamlit run app.py
   ```

## Project Structure
- `app.py` – Main Streamlit application.
- `train_models.py` – Model training.
- `src/` – Supporting Python modules.
- `requirements.txt` – Required libraries.
